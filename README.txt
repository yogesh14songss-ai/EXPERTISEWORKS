YOGESH PARMAR — PERSONAL PROJECT HUB

FILES
- index.html       Main home page with four destinations: BCA Projects, Professional Work, Music Projects, and New Features.
- style.css        Paper-inspired home page theme, responsive layout, and card styles.
- programming.html Existing programming hub containing C, C++, DSA, Web Technology, Backend with PHP, and CONM.
- programming.css Styling for the programming hub.
- site-links.js    Central place to add future website and social URLs.

DEPLOYMENT
Upload all six files to the same website root. Keep the filenames unchanged.
The home page is index.html. The BCA Projects card opens programming.html.
The home page uses the paper-style dynamic-lines background URL provided during the design request; an internet connection is needed to load that image.

ADD LINKS LATER
Open site-links.js and paste the full URL between the quotation marks.
- projectUrls.professional controls the Professional Work card.
- projectUrls.music controls the Music Projects card.
- socialUrls.linkedin / instagram / snapchat / drive / github control the footer links on both pages.
Leave any value empty until its destination is ready; unconfigured links will remain inactive.
The New Features card scrolls to the roadmap section on the home page.
